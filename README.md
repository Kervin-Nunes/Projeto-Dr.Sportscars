# Dr. Sportscars 🚗

Landing page para a marca fictícia **Dr. Sportscars**, desenvolvida como projeto prático de front-end com foco no uso de **SCSS** e automação de build com **Gulp**.

## 🛠 Tecnologias utilizadas

- HTML5
- SCSS (pré-processador CSS)
- Gulp (task runner)

## 📁 Estrutura

- `source/` — arquivos fonte SCSS
- `build/` — arquivos compilados gerados pelo Gulp
- `images/` — imagens do projeto

## 🚀 Como rodar

```bash
npm install
npx gulp
```
